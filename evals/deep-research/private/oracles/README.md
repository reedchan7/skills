# Oracles

One file per brief, written from primary sources at freeze time with the
retrieval date. Each lists required facts (with the owning source), the
expected tier and shape behaviour, known traps (claims a careless run states
as fact), and contested points the report must surface as disagreements.
Oracles are never shown to the generating agent.
